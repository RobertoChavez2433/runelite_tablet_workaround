## Review Notes

Three items changed during implementation. Each is documented where it appears; collected here for handoff clarity.

1. **B3 deviation** — draft said "skip PulseAudio for simplicity on Phase 2.1". Reality: the launcher starts PulseAudio anyway because it's Termux-native (no proot cost) and RL's static-init paths read `PULSE_SERVER`. Cost-free win; the simpler branch was correct. PULSE_SERVER falls through to empty when pulseaudio isn't installed — RL uses null-audio backend.

2. **U5 discovered post-launch** — draft's U-list didn't anticipate that Termux lacks fontconfig and system fonts. The FontManager `Fontconfig head is null` runtime error appears AFTER main() banner prints (i.e. after Phase 2.1 exit is met), so it doesn't gate this spec — but it will gate Phase 3 FPS A/B. `pkg install fontconfig` + install a TTF font as Phase 3 prep.

3. **Ad-hoc test wrapper** — because `run-as com.termux` doesn't configure HOME/PREFIX and adb shell holds the stdin of its foreground child (causing the JVM to die on disconnect), a tiny `scripts/native-launcher-wrapper.sh` was written for on-device verification. It sets HOME/PREFIX and double-forks via setsid. This wrapper is committed as a temporary ad-hoc test helper; once Phase 2.2 wires the Kotlin `RuneLiteSessionService` to invoke `launch-runelite-native.sh` directly with proper env, the wrapper becomes redundant and should be removed.
